# Simple Calculator

Terminal calculator in Python built with defensive programming: it handles unexpected input without crashing.

## Features
- Addition, subtraction, multiplication and division
- Validates numeric input and re-prompts on invalid entries
- Guards against division by zero
- Enter `Q` to quit

## Requirements
Python 3 (standard library only).

## Usage
```bash
python "SIMPLE CALCULATOR.py"
```
